# First-Time User Journey

## Overview
This document maps the critical first session experience for NewMoji. Research shows we have ~60 seconds to hook a user and ~5 minutes to create value. This journey is designed to get them from curious to engaged to "I'm coming back tomorrow."

---

## Journey Map: First Session

### Stage 0: Discovery (Before the app)

**How they find us:**
- 🤝 Friend shares emoji headline on Instagram story
- 📱 TikTok video showing the app in action
- 🏫 Teacher recommends it
- 🔍 Google search for "news app for gen z"
- 📰 Article about news literacy tools
- 🎮 App store browsing

**Mindset on arrival:**
- Curious but skeptical
- Low commitment
- Expect it to be like other news apps (boring)
- Will judge in first 10 seconds

---

**User reaction we're aiming for:**
- "Wait, this is different"
- "Those emoji actually make sense"

- Slight smile or curiosity

**Red flags to avoid:**
- ❌ Too many headlines (overwhelming)
- ❌ Cluttered interface
- ❌ Unclear what to do next
- ❌ Loading time > 2 seconds
- ❌ Asking for account/permissions immediately

## Critical Success Metrics for First Session

### Must achieve:
1. **60+ seconds time spent** (enough to complete one story)
2. **80%+ complete first story** (progressive disclosure works)
3. **40%+ try a challenge** (engage with education)
4. **30%+ read second story** (want more)
5. **20%+ enable notifications** (permission to re-engage)

### Red flags:
- 🚩 Average session < 30 seconds (not hooking)
- 🚩 Bounce rate > 50% after first headline (emoji headlines don't work)
- 🚩 Challenge completion < 20% (too hard or not interesting)
- 🚩 Return rate < 50% within 7 days (no retention)

## What Could Go Wrong? (Failure Modes)

### Failure Mode 1: "This is childish"
**Symptom:** User sees emoji headlines, eye rolls, closes app
**Prevention:**
- Onboarding copy: "News that doesn't suck" (not "Fun news for kids!")
- Sophisticated color palette and typography
- Substance quickly visible (not all fluff)
- Testimonials from older teens

### Failure Mode 2: "I don't get it"
**Symptom:** User taps around confusedly, gives up
**Prevention:**
- Clear micro-copy on first visit
- Obvious tap targets
- Progressive disclosure explained in first tooltip
- Can't get lost (always can go back)

### Failure Mode 3: "This is boring/preachy"
**Symptom:** User completes first story, doesn't engage with education
**Prevention:**
- Educational content is optional (can skip challenges)
- Tone is conversational, not lecture-y
- Gamification makes learning feel like play
- Quick wins (feel smart immediately)

### Failure Mode 4: "Not worth my time"
**Symptom:** User reads one story, never returns
**Prevention:**
- Hook in first story must be strong
- Clear value proposition ("you just learned to spot bias")
- Visible progress (media literacy score)
- Streak mechanic (come back tomorrow)

### Failure Mode 5: "Just another news app"
**Symptom:** User doesn't see differentiation
**Prevention:**
- Immediate visual differentiation (emoji headlines)
- Progressive disclosure feels different from scrolling articles
- Educational angle is clear
- Gamification is visible

## A/B Testing Opportunities

### Test 1: Emoji headline complexity
- **A:** Simple emoji (3-4 max)
- **B:** Complex emoji stories (5-6 emoji)
- **Metric:** Tap rate

### Test 2: First story topic
- **A:** Light/fun topic (tech, entertainment)
- **B:** Serious topic (politics, climate)
- **Metric:** Completion rate

### Test 3: Challenge timing
- **A:** Challenge after Level 2
- **B:** Challenge after Level 3
- **Metric:** Challenge participation rate

### Test 4: Notification permission ask
- **A:** Ask after first story
- **B:** Ask after 3 stories
- **Metric:** Permission grant rate

### Test 5: Onboarding intensity
- **A:** No tutorial, just tooltips
- **B:** 30-second interactive tutorial
- **Metric:** Time to complete first story

## User Testing Script

**When testing the first-time experience:**

**Setup:**
- Hand them a phone with app installed
- Say: "A friend sent you this, check it out"
- Don't explain anything else
- Watch silently

**Observe:**
- ⏰ How long until first tap? (Should be < 10 sec)
- 😊 Do they smile or look intrigued?
- 🤔 Do they look confused at any point?
- 📱 Do they scroll, tap, or go back?
- ⏱️ How long do they spend?
- 🔁 Do they try a second story?

**After 5 minutes, ask:**
1. What do you think this app is for?
2. Would you actually use this? Why or why not?
3. What did you like? What annoyed you?
4. Did anything confuse you?
5. Would you tell a friend about it?
6. What would make you open it tomorrow?

**Red flags to listen for:**
- "Is this for kids?"
- "I don't understand what I'm supposed to do"
- "This is just news but with emoji"
- "Why would I use this instead of TikTok?"
- "The educational stuff feels like homework"

---

## Design Principles for First Session

1. **Hook in 10 seconds** - Visually different immediately
2. **Value in 60 seconds** - Complete one story fast
3. **Aha moment in 90 seconds** - "I'm actually learning"
4. **Second engagement in 180 seconds** - Want to read another
5. **Reason to return in 300 seconds** - Streak, score, curiosity

**Every second counts in the first session. If we don't hook them here, we never will.**
