# Returning User Journey

## Overview
After the first session hooks them, the returning user experience needs to build habits, deepen learning, and create long-term value. This journey maps Days 2-30 and beyond.

---

## Day 2-7: Habit Formation (Critical Period)

### Goal
Convert curious first-timer into daily user with a streak habit.

**Morning notification (9-10am):**
```

**Success metric:** 70%+ return on Day 2

## Retention Mechanisms

### Daily Engagement Drivers

**1. Streak Protection (Loss Aversion)**
```
Day 45: "🔥 45-day streak! Don't lose it now!"
Day 46: User forgets to open
Day 47: "⚠️ Your streak is about to break!"
         + One-time streak freeze available
```

**2. Fresh Content Daily**
- New headlines every morning
- Daily challenges vary
- Current events keep it relevant

**3. Progress Visualization**
```
┌─────────────────────────────┐
│  📈 Your Growth              │
├─────────────────────────────┤

## Re-engagement for Lapsed Users

### Lapsed User Scenarios

**Scenario 1: Missed 2-3 days**
```
📱 Notification:
"🔥 Your 23-day streak can still be saved!
Come back before midnight"
```

**If they return:**
- Celebrate comeback
- Offer streak freeze for future
- Remind them of progress

---

**Scenario 2: Missed 7+ days**
```
📱 Notification:
"We miss you!
Check out what happened while you were gone:
🌍⚡🔥 [Major event headline]"
```

**If they return:**
- Don't guilt them about broken streak
- Show what they missed
- Offer "fresh start" bonus
- Highlight new features

---

**Scenario 3: Dormant 30+ days**
```
📱 Email (if provided):
"Your media literacy score: 78/100
Don't lose what you learned!

[Major current event they'd care about]

Come back and see how much you remember"
```

**If they return:**
- Quiz on old learnings (show retention)
- Celebrate what they remember
- Update on new content
- New streak starts fresh

## Churn Risk Indicators & Interventions

### Warning Signs

**User is likely to churn if:**
- 🚩 Session time decreasing week-over-week
- 🚩 Challenge completion rate drops below 20%
- 🚩 Hasn't read a story in 3 days
- 🚩 Opened app but bounced < 30 sec (3x in a row)
- 🚩 Unsubscribed from notifications

### Interventions

**If engagement dropping:**
```
┌─────────────────────────────┐
│  💡 Quick check-in           │
├─────────────────────────────┤
│  We noticed you've been less │
│  active lately. What can we  │
│  do better?                  │
│                              │
│  □ Content not interesting   │
│  □ Too time-consuming        │
│  □ Too difficult             │
│  □ Not relevant to me        │
│  □ Other: __________         │
│                              │
│  [Send feedback]             │
│  [I'm fine, thanks]          │
└─────────────────────────────┘
```

**Adaptive responses:**
- "Not interesting" → Better personalization
- "Too time-consuming" → Shorter stories mode
- "Too difficult" → Adjust difficulty down
- "Not relevant" → Topic preferences

## The Habit Loop

**Trigger:** Daily notification + streak anxiety
↓
**Routine:** Open app, read 2-3 stories, complete challenge
↓
**Reward:** Progress visible, feel smarter, dopamine hit
↓
**Investment:** Streak gets longer, score gets higher, identity forms
↓
**Return:** Don't want to lose progress, curious about tomorrow

**This loop must be effortless and rewarding every single time.**
