# Gamification Design

## Overview
Gamification in NewMoji must walk a fine line: engaging enough to build habits, but not so game-like that it undermines the educational mission. We're not building Candy Crush—we're building a tool that helps Gen Z become critical thinkers.

---

## Core Principles

### 1. Reward Learning, Not Just Engagement
**Good:** +20 points for correctly identifying bias
**Bad:** +20 points for opening the app

### 2. Make Progress Visible
Users should always know: "I'm getting better at this"

### 3. Respect Their Intelligence
Gen Z can tell when they're being manipulated. Gamification should feel genuine.

### 4. Create FOMO (Fear of Missing Out) Without Toxicity
Streaks yes, but with forgiveness. Competition optional, not required.

### 5. Tie Everything to Real Skill Development
Every badge, point, and streak should map to actual media literacy improvement.

## Points System

### How You Earn Points

**Reading & Engagement:**
- Complete a story (read to Level 2): **5 points**
- Read multiple perspectives (Level 3): **10 points**
- Deep dive (Level 4): **15 points**
- Read from opposing political viewpoint: **+5 bonus**

**Learning & Challenges:**
- Answer challenge correctly (first try): **15 points**
- Answer challenge correctly (second try): **10 points**
- Complete daily challenge: **20 points**
- Finish learning module: **30 points**
- Pass learning path assessment: **50 points**

**Quality Engagement:**
- Read 3+ different sources on same story: **20 points**
- Fact-check a claim: **25 points**
- Complete reflection prompt: **10 points**
- Share thoughtful insight (optional): **15 points**

**Consistency:**
- Daily streak bonus: **+10 points per day**
- Weekly challenge completion: **50 points**
- Monthly milestone: **100 points**

### Points Decay?
**No.** Points are cumulative achievement, not currency. You never lose points.

### What Points Do
- Unlock achievement badges
- Track overall engagement
- Leaderboard ranking (optional)
- Bragging rights

**Points don't unlock critical features.** Education is always free.

## Streak System

### How Streaks Work

**Daily Streak:**
- Open app and read at least 1 story per day
- Counter visible: "🔥 23-day streak!"
- Resets to 0 if you miss a day

### Streak Protection (Forgiveness Mechanism)

**One Free "Streak Freeze" per week:**
```
┌─────────────────────────────┐
│  ❄️ Streak Freeze Available  │
├─────────────────────────────┤
│  Missed yesterday? That's ok!│
│  Use your weekly freeze to   │
│  protect your 23-day streak. │
│                              │
│  [Use Streak Freeze]         │
│  [Start Fresh]               │
│                              │
│  Next freeze available in 6  │
│  days                        │
└─────────────────────────────┘
```

**Why:** Life happens. Don't punish users for being human.

### Streak Milestones

- **7 days:** "Week Warrior" badge
- **14 days:** "Two Week Scholar"
- **30 days:** "Monthly Mastermind"
- **60 days:** "Consistent Learner"
- **100 days:** "Century Club"
- **365 days:** "Year of News" (🏆 Elite badge)

### Streak Notifications

**Day of:**
```
📱 9am: "Good morning! Keep your 23-day streak alive 🔥"
```

**End of day warning:**
```
📱 8pm: "Only 4 hours left to maintain your streak!"
```

**After missing:**
```
📱 Next day: "Your 23-day streak ended, but you learned
so much! Ready to start again? 🔥"
```

**Tone:** Encouraging, not guilt-tripping.

## Levels System

### Experience Levels (1-50)

Users level up based on cumulative points:

```
Level 1:  Curious Newbie        (0 pts)
Level 5:  Engaged Reader        (500 pts)
Level 10: Critical Thinker      (2,000 pts)
Level 15: Informed Citizen      (5,000 pts)
Level 20: Media Literacy Scholar (10,000 pts)
Level 25: News Expert           (20,000 pts)
Level 30: Bias Detective        (35,000 pts)
Level 40: Truth Seeker          (75,000 pts)
Level 50: Master of Information (150,000 pts)
```

**Progression curve:** Exponential (harder to level up over time)

### Level Benefits

**Mostly cosmetic:**
- Cool titles
- Profile customization
- Special badge colors
- Leaderboard prestige

**Small functional perks:**
- Advanced challenges unlock at Level 10
- Custom topics at Level 15
- Contributor mode at Level 20

**Never paywall education:** All learning paths available to everyone.

## Notifications Strategy

### Notification Types

**1. Streak Maintenance (Daily)**
```
9am: "Good morning! Keep your 45-day streak going 🔥"
8pm: "4 hours left to maintain your streak!"
```

**2. Challenge Reminders (3x/week max)**
```
"Today's challenge: Read an opposing viewpoint"
"Weekly challenge ends in 2 days!"
```

**3. Achievement Celebrations (Immediate)**
```
"🎉 You earned 'Bias Buster' badge!"
"🏆 New high score: 78/100 media literacy!"
```

**4. Learning Nudges (2x/week max)**
```
"You're 60% through 'Source Credibility' - finish it!"
"New learning path unlocked: Advanced Critical Thinking"
```

**5. Re-engagement (After 3+ days inactive)**
```
"Miss you! Here's what happened this week: [headline]"
```

**6. Major News Alerts (Rare - only huge stories)**
```
"🚨 Breaking: [Major event]. Here's what you need to know"
```

### Notification Principles
- **User control:** Customize all notification types
- **Not spammy:** Max 2-3 per day
- **Respectful timing:** Not late at night
- **Valuable:** Every notification should provide value
- **Opt-in for optional features**

## What We're NOT Doing

### ❌ Predatory Gamification

**No dark patterns:**
- No infinite scroll (curated daily feed)
- No artificially slowed progress
- No pay-to-win mechanics
- No FOMO beyond healthy streak motivation
- No shame/guilt for missing days
- No toxic competition

**No addiction optimization:**
- We want daily habit, not compulsion
- Quality engagement > time spent
- Learning outcomes > engagement metrics
- User control > platform control

## A/B Testing Opportunities

### Test 1: Streak Forgiveness
- **A:** No streak freeze
- **B:** 1 freeze per week
- **C:** 2 freezes per month
- **Metric:** Long-term retention

### Test 2: Point Values
- **A:** High points for everything
- **B:** Lower points, feel more earned
- **Metric:** Perceived value of achievements

### Test 3: Daily Challenge Difficulty
- **A:** Easy challenges (80% completion)
- **B:** Medium challenges (50% completion)
- **C:** Hard challenges (30% completion)
- **Metric:** Engagement + learning outcomes

### Test 4: Badge Rarity
- **A:** Many badges, easier to earn
- **B:** Fewer badges, harder to earn
- **Metric:** Achievement satisfaction

### Test 5: Leaderboard Visibility
- **A:** Prominent on home screen
- **B:** Hidden in profile
- **C:** Completely opt-in only
- **Metric:** Competitive behavior + user sentiment

## Success Metrics

### Engagement Metrics
- Daily active users
- Streak maintenance rate
- Average session length
- Return rate

### Learning Metrics
- Challenge completion rate
- Assessment scores
- Learning path completion
- Skill improvement over time

### Gamification Health
- Are users gaming the system?
- Does gamification enhance or detract from learning?
- User satisfaction with gamification elements
- Balance between fun and educational
